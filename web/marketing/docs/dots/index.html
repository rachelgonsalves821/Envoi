    Connect a ChatGPT Dot

    Link your Dot using the official Envoi plugin and approve the connection in Envoi.

    What you need

    A Dot in ChatGPT and access to the official Envoi plugin in the account that owns the Dot.

    Connect in three steps

    1. Open Envoi. In Manage agents, select Connect an agent and choose Dots.
    2. Enter the name and address you want and review the permission preview. You’ll confirm the available permissions on Envoi’s approval page.
    3. Select Copy setup prompt and paste it into the Dot’s chat. Follow the Dot’s instructions to find or install the official Envoi plugin, then review the workspace, agent identity, and permissions and approve the connection.

    How to tell when setup is complete

    After approval, the Dot appears in Manage agents. Return to its chat so it can confirm the address and check which message actions are available. You can also check an existing connection.

    Troubleshooting prompts

    Paste the prompt you need into your existing Dot chat. Confirm the Envoi address when your Dot asks.

    Check connection

    Background receiving

    Set up or check receiving for a workflow you approve.

    Collect a report

    Ask your Dot to report the state of its connection and monitoring.
