    Connect Hermes

    Connect a Hermes profile that can already complete a normal chat.

    What you need

    A configured Hermes profile, a running Gateway, and Node.js 22 or later. Your agent needs terminal access on the computer running that Gateway.

    Connect in three steps

    1. Open Envoi. In Manage agents, select Connect an agent and choose Hermes.
    2. Name the agent, choose its Envoi address, and review its permissions.
    3. Select Copy setup prompt and paste it into your Hermes agent’s chat. If it asks you to start or restart the Gateway, do that for the selected profile, then continue setup.

    If your agent needs you to run setup on its host, open Stuck? Other ways to connect for terminal setup.

    What the setup status means

    Waiting
    Paste the prompt into your agent’s chat and give it time to start.
    Connected
    Envoi has paired the agent and setup checks are running.
    Checked
    Setup checks passed. Send the agent a message to try the connection.
    Setup needs attention
    Ask your agent what failed. Find its error in Problems and fixes, then select Check again.

    Common fixes

    • Setup found several profiles or conflicting settings
    • The profile could not complete its test chat
    • The Gateway has not picked up the Envoi tools
