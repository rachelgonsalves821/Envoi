# Phase B hosted artifact preflight

Run this read-only check on a clean, built checkout of the **selected exact release**, after staging serves that release and after fresh Hermes and OpenClaw profiles have installed the reviewed files. It checks the two public downloads, the served skill, the privately supplied helper and the installed copies against that checkout. It also checks `/health` and `/ready`. It neither enrolls an agent nor changes staging.

The operator supplies the absolute paths from the **actual test profiles**, not a source file reused as an installed path. Keep profile and helper locations private. The report contains hashes and check results, but no path, token, claim code or raw response.

```powershell
$candidate = '<selected integrated 40-character SHA>'
node integrations/gates/phase-b-artifact-preflight.mjs `
  --origin https://sinaloa-staging.rachelgonsalves821.workers.dev `
  --sha $candidate `
  --installed-hermes-skill '<Hermes skill path>' `
  --installed-hermes-helper '<Hermes private helper path>' `
  --installed-hermes-connector '<Hermes connector bundle path>' `
  --installed-openclaw-skill '<OpenClaw skill path>' `
  --installed-openclaw-helper '<OpenClaw private helper path>' `
  --installed-openclaw-connector '<OpenClaw connector bundle path>' `
  --installed-openclaw-bundle '<OpenClaw runtime bundle path>'
```

The script requires a clean checkout at the exact SHA, full critical readiness, matching local and served release manifests, and identical local/served/installed bytes for each public artifact. It rejects redirects, insecure origins, and symlinked installed files. The helper is private and is compared only with the built candidate; there is no public helper download to compare. Record the sanitized report and the exact file-to-host mapping in the private hosted worksheet. A successful `ARTIFACTS_MATCHED` is one input to the hosted packet, not a 21-row hosted pass, closed-app wake pass or paired Worker/image rollback.

Run `npm run build` on the selected checkout before this check to produce `integrations/onboarding/dist/envoi-link.mjs`. A build that changes tracked generated bytes or leaves the checkout dirty requires review and a new exact candidate; do not dismiss `cleanCandidate: FAIL`. If any artifact differs, stop and repin the release rather than mixing files from different heads.
