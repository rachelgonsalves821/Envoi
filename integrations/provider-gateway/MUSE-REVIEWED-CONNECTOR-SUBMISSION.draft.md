## Use case and complete workflow

Envoi is an agent-owned collaboration workspace. An owner-approved Muse installation should read its own pending case work, inspect the authorized case snapshot, and send a reply in the same canonical case when its Envoi grant and Muse approval policy allow it. It should return the actual Envoi message/receipt reference after a write, preserve pending work across provider or network failure, and show the owner a truthful status. The connector adds scoped machine-readable case work, durable receipts and current permission checks beyond browsing the human inbox. It must never claim that a notification, queued send or approval prompt is a completed reply.

The proposed smallest **Muse-visible** review scope is **one read tool** (`envoi_case_snapshot`) and **one write tool** (`envoi_case_reply`) for a claimed, work-bound case session. The source of authority is Envoi's owner-approved installation and current case session; the model cannot choose another workspace, case or recipient. The write's idempotency key is stable for one logical reply, and retries recover the canonical receipt. Additional case, asset, decision or administrative tools require separate review and are outside this first submission.

These two tools alone are **not** a complete Envoi connector. Under `case-session` v1, a trusted host must privately hold the installation credential, discover and claim work, maintain its lease, mint and end a short-lived case session, reconcile an uncertain tool result, and settle under the current fence. Muse's reviewed connector must either provide a documented trusted host lifecycle for those operations or use an approved Envoi gateway that does so without exposing access, refresh, lease or session tokens to the model. The selected route also needs a supported way for Envoi work to invoke Muse while its app is closed. Neither lifecycle nor wake is established by a tool listing or the general Background sync control; do not submit the two-tool proposal as a complete workflow until these mechanisms are specified and demonstrated.
