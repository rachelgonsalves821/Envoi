# REQUEST Lane A: provider browser gateway Stage 2 actions

**Status:** Lane B review request, 2026-10-21. No Stage 2 contract, fixture, implementation, route enablement, provider acceptance or live-host pass is claimed. Rachel/Codex owns this request and its eventual client consumption. The canonical contract and fixtures remain a separate publication and exact-version approval.

**Starting point:** The integrated [Stage 1 implementation](IMPLEMENTATION.md) and approved [`provider-browser-poll` v1 text](BROWSER-POLL-CONTRACT.draft.md) bind one delegated browser session to an owner-confirmed installation. Its cookie can read a bounded pending-work projection and acknowledge **alert presentation only**. [The canonical handoff](../../docs/architecture/agent-native-v2/handoffs.md#provider-browser-poll-v1) explicitly excludes claim, send, settlement and assets. Existing `case-session` v1 and `case-tools` v1 govern claims, scoped sessions, typed tools, idempotency and fences for trusted clients. Stage 2 needs a gateway mapping to those services; a browser cookie must never become a raw agent or case-session bearer token.

## Independent host evidence after implementation

This contract can make a gateway action technically possible. It cannot prove Muse or Instinct supports a private delegated session, scheduled browser work or unattended reply. For each exact host/account, record installed route and owner authorization, native task ID/readback/cadence, private session persistence, two independently timed items while its app is closed, host invocation, authenticated fetch, provider prompt, canonical reply and settlement receipts, then missed tick/restart/duplicate/pause/revoke. Keep `read notification`, `host woke`, `write approved` and `reply completed` separate. Instinct's selected test is native Envoi work, not an email bridge.

Instinct's assistant told Rachel on 2026-10-21 that it has **no persistent SSE client**, runs scheduled/event tasks, has not yet tried a live API, and reports no independently viewable task log dashboard. It claims a scoped, expiring standing reply grant and temporary private credential use. Treat these as unverified host claims. The current generic REST helper requires SSE and rejects scheduled polling, so publication must decide a scheduled native route and exact Envoi authority mapping; a natural-language host grant alone cannot authorize canonical work or writes.
