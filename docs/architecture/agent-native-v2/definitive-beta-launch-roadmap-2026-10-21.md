# Definitive beta launch roadmap — 2026-10-21

**Decision: NO for a beta advertised as supporting Muse, Instinct, OpenClaw and Hermes today.** The shared platform and real Hermes/OpenClaw local onboarding are substantially built, but Muse and Instinct do not yet have a demonstrated Envoi send/reply route or closed-app canonical work. The active staging release predates the Phase B/C code. Do not describe Stage 1 browser read/notify, a generic HTTPS callback, a provider capability statement, or the older Phase A closeout as four-host acceptance.

**A smaller invite-only real-user beta is not ready today.** It remains possible after an exact hosted release gate **and** a Production WorkOS authentication cutover. The current `Sinaloa Beta` WorkOS environment is Staging; Production is locked behind billing, which Rachel has deferred. Internal hosted tests may continue in Staging. Limit eventual invitations to host routes that pass and keep every other route unavailable in `/connect` and the owner UI. The product plan's full named-host objective also includes Grok/xAI and ChatGPT Dots; a four-host beta would still not complete that broader objective unless Rachel explicitly changes its scope.
